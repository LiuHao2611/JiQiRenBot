## 本版改了什么

第一版按时间线铺开的是**萧炎自己的**斗技、武器、异火，跑题了。本版以**门派 / 势力**为唯一主体：
每一行只写「这个势力自己拥有、传承、镇派、守护」的东西。主角个人装备与自创斗技一律不列，
统一放在 [第六节「不计入清单」](#六明确不计入本表的主角个人配置) 说明边界。
若某物虽被主角使用、但**归属某门派**（例：骨灵冷火属药老／药族，帝印决属古族，
三千雷幻身属风雷阁），则仍按门派归属列在门派条目里，并注明「后传于萧炎」。

标注约定：
- **[游戏]** = 反编译资源里真实出现（附文件名）
- **[游戏原创]** = 游戏自造，原著没有同名设定
- **[运行]** = 本仓群聊小游戏当前实装
- **[原著]** = 小说设定，游戏未实装或仅提及
- **[冲突]** = 游戏与原著口径不一致

**一个前提**：游戏没有阵营数值表，势力以剧情脚本、地图名、敌对 NPC 表存在；
且斗技有两套数据（HD 实机面板 4 门 vs 图鉴 `d__hs` 5 门）。以下门派专属内容主要来自
**NPC 战斗台词、剧情道具与地图配置**，不是主角技能表。

### 1.2 逐派明细

#### 萧家（乌坦城）
- **专属斗技 [原著]**：`狂狮怒罡`（玄阶中级，风属性，**只有族长有资格修炼**）、`炼火焚`（黄阶高级，萧家最顶尖火属性功法）。
- **特殊物品 [游戏]**：**三枚萧族印信** —— `s__d50` 族长藏于后山，`s__d51/52/53/54` 集齐后 `s__d53` 明示「只有出示族长的三枚印信才能进入」萧家密室。
- **器物 / 血脉 [游戏]**：萧家密室、萧家后山；过场 `tt3` 明写「从**萧玄**体内涌现血线…萧炎体内的**斗帝血脉**逐步觉醒」—— 这是萧族（后期远古八族之首）的传承，前期只露伏笔。
- **人物 [游戏]**：萧战（族长）、萧鼎 / 萧厉（石漠城漠铁佣兵团）、萧玉、萧家族人（`s__n`）。

#### 云岚宗（云岚山）— 游戏里资料最完整的门派
- **镇派绝学 [游戏原创]**：**「天道神雷剑诀」**，`s__d60` 云棱「再吃我一记天道神雷剑诀！」、`d__bfont` 完整吟唱「煌煌天威／六道众生／皆以血引／化为神雷／斩！！！」+「让你尝尝我绝学的厉害」。**原著无此招**，云棱原著没有这个斗技名。
- **合击 / 阵法 [游戏]**：`万剑归宗！`（`d__bfont` 弟子合击喊话）；**护宗大阵**，`s__d56`「众弟子，结阵！！」「击败阵眼『执法弟子』后，方能继续前进」，`d__bfont` 多次「阵眼已破！快撤！」「长老要启动大阵了」。
- **专属场地 / 器物 [游戏]**：**天刑台**（`d__bfont`「上了前方天刑台，可就没有丝毫退路了」、`s__d56`「将萧炎击杀在这天刑台上」）；**云岚宗守护兽**，`s__d56` 提示「只有利用云岚宗的守护兽方能一战！…骑上神兽」。
- **专属斗技 [原著]**：`青木剑诀`（玄阶低级，云岚宗功法）；`爆步`（玄阶中级，云韵所赠身法）。
- **人物与层级 [游戏]**：云山（老宗主，斗宗，`s__d60`「老宗主…你是云山！？」）、云棱（大长老，`s__d59` 自称「我是云岚宗大长老」）、纳兰嫣然（**大师姐 / 下任宗主**，`s__d61`）、执法弟子、云岚宗弟子。
- **[冲突] 宗主称谓不统一**：`s__d59` 云棱说「今日**宗主尚未回来**，因此这次比试由老夫主持」、`s__d56` 纳兰嫣然说「禀报宗主，请**她**辨明是非」→ 宗主是女性且当时不在场（原著为云韵）；但 `s__d60` 云山自称「**本宗主**要按照宗门规矩将你囚禁」。脚本内「老宗主 / 宗主」混用，本文按原文照录，不强行统一。
- **附庸**：墨承是「我云岚宗**外门执事**」（`s__d59`）→ 墨家属云岚宗外门体系。
