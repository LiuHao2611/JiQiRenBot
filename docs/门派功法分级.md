# 斗破门派功法分级（结合原著）

> 阶位：**天 / 地 / 玄 / 黄**，各分 低·中·高（原著体系）。
> 依据优先级：**C1**（张谦方《斗破设定整理·斗技整理》，B站 opus 959287705904087041）＞起点/百科＞百度知道。
> 「**未标**」= 原著与资料均未给出明确阶位（多为龙套技）；不臆造。
> 游戏映射：**黄/玄→普通**，**地/天→高阶**，**特殊（秘法/瞳术/血脉）→特殊**，**未标→普通**。
